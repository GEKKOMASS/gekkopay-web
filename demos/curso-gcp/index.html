Módulo 2 · Lección 2.2 · Muestra real del material

RAG empresarial: que el agente responda con los documentos de la empresa

RAG (Retrieval-Augmented Generation, "generación aumentada con recuperación") es la técnica para que un modelo responda buscando primero en documentos propios, en vez de inventar con lo que aprendió en su entrenamiento.

⏱ 4 horasNivel intermedioRAG EngineAgent SearchPython
  1. Explicar el flujo RAG completo y cuándo conviene frente al fine-tuning (reentrenar el modelo).
  2. Crear un corpus en RAG Engine, importar documentos y ajustar el troceado (chunking).
  3. Conectar el corpus a un modelo Gemini como herramienta de recuperación y medir la calidad de las respuestas.

4 · Laboratorio guiado (extracto)

⚠ Extracto real del laboratorio 2.2 del aula. Usa el cliente actual agentplatform (el módulo clásico vertexai.rag está en desuso), embeddings multilingües para documentos en español y el modo Serverless de RAG Engine en us-central1, que evita el cobro fijo del modo predeterminado. Google cambia estos servicios con frecuencia: el curso se revisa antes de cada dictado.
  1. Preparar el entorno en Cloud Shell (la terminal del navegador de Google Cloud): 
    python3 -m venv ~/lab22 && source ~/lab22/bin/activate
pip install "google-cloud-agentplatform>=2.0.1" google-cloud-storage google-genai
  2. Crear el corpus e importar los documentos con troceado de 512 tokens: 
    import os, agentplatform
from agentplatform import types
from google.genai import types as gt

client = agentplatform.Client(project=os.environ["GOOGLE_CLOUD_PROJECT"], location="us-central1")
emb = types.RagEmbeddingModelConfig(
    vertex_prediction_endpoint=types.RagEmbeddingModelConfigVertexPredictionEndpoint(
        endpoint="publishers/google/models/text-multilingual-embedding-002"))
corpus = client.rag.create_corpus(rag_corpus=types.RagCorpus(
    display_name="politicas-nordia",
    rag_vector_db_config=types.RagVectorDbConfig(rag_embedding_model_config=emb)))
client.rag.import_files(name=corpus.name, import_config=types.ImportRagFilesConfig(
    gcs_source=gt.GcsSource(uris=["gs://TU_BUCKET/*"]),
    rag_file_transformation_config=types.RagFileTransformationConfig(
        rag_file_chunking_config=types.RagFileChunkingConfig(chunk_size=512, chunk_overlap=100))))
  3. Probar la recuperación antes de conectar el modelo (si aquí no aparecen los fragmentos correctos, el modelo tampoco responderá bien): 
    res = client.rag.retrieve_contexts(
    vertex_rag_store=gt.VertexRagStore(rag_resources=[
        gt.VertexRagStoreRagResource(rag_corpus=corpus.name)]),
    query=types.RagQuery(text="¿Cuántos días de teletrabajo tengo?",
                         rag_retrieval_config=gt.RagRetrievalConfig(top_k=3)))
print(res)
  4. Reto evaluable: repite las 10 preguntas del banco de pruebas con fragmentos de 64, 128 y 512 tokens y registra cuántas respuestas citan el documento correcto. Conclusión esperada: no existe un tamaño único; se mide.
  5. En el laboratorio completo: activar el modo Serverless, conectar el corpus a Gemini como herramienta de recuperación, generar respuestas con cita de la fuente y comparar con grounding web.

Proyecto final · Módulo 4

Asistente interno de Nordia, en producción

Cada participante (o equipo, según el formato del grupo) entrega un agente construido con ADK (Agent Development Kit, el kit de código abierto de Google para programar agentes; en el curso se usa Python), conectado a RAG Engine, protegido con Model Armor (el filtro de seguridad de Google para prompts y respuestas) y desplegado en Agent Runtime (antes Agent Engine) con monitoreo.

CriterioPesoQué se evalúa
Funcionalidad25 %Responde con las políticas correctas, cita la fuente y usa al menos una herramienta externa (API o base de datos).
Calidad medida20 %Conjunto de evaluación propio (mínimo 20 preguntas) con métricas de exactitud y fidelidad a la fuente.
Seguridad20 %IAM con mínimo privilegio, secretos en Secret Manager, plantilla de Model Armor contra prompt injection (instrucciones maliciosas escondidas en el texto) y prueba documentada de ataque bloqueado.
Operación (MLOps)20 %Despliegue reproducible, versión del agente, registros y trazas en Cloud Logging y Cloud Trace, alerta configurada.
Costos y documentación15 %Estimación de costo mensual, presupuesto con alerta en Billing y README (documento de instrucciones) de arquitectura.
